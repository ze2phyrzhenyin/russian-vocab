# ADR 0003：固定 FSRS 发布版与显式冲突处理

状态：采用，2026-10-24。

npm 稳定版 ts-fsrs 为 5.4.2，而仓库主分支已经展示 v6 的异步构造和不同运行要求。本轮固定已检查的 5.4.2 / FSRS-6、参数与命名 Rating，关闭 fuzz，不引入优化器或 WASM。

客户端先原子保存事件和会话，再同步；服务端去重并检查基线版本。正式事件驱动长期调度，纠错曝光为 practice。陈旧版本或异常时钟形成持久冲突，用户可保留为练习或放弃；不以最后写入的整张记忆状态覆盖历史。

这个方案有意保留显式冲突界面，不自动猜测跨设备离线作答的真实顺序。未来自动重算必须先定义可审计的排序、时钟处理和参数迁移，并使用现有事件流回放测试证明结果。

# ADR 0004：少量自有语义组件与按需本地 OCR

状态：采用，2026-10-24。

默认方向保留 React、Tailwind、Motion 和移动优先设计。首轮没有引入 shadcn 生成器：现有页面只需要一组边界清楚的按钮、表单、弹层和列表，使用自有语义组件可避免生成器与主题配置维护。代价是焦点、键盘、触控、对比和弹层行为由本项目负责，必须在 Playwright/axe 与视觉检查中验收；不能因组件少而省略可访问性。

OCR 选择 Tesseract.js 浏览器 worker、自托管俄语和中文模型。图片识别在设备本地完成，不需要云端 Key；结果必须编辑确认后才入库。复杂双栏或低质量图像保留草稿和人工修正；PaddleOCR / 多模态 provider 延后到实际失败样例足以说明需求时再采用。正常启动不重新下载整套 OCR 依赖。

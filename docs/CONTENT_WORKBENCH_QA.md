# 注解工作台验收

2026-10-24，在本地隔离数据库、已构建的 Next.js standalone 应用上完成真实 Chromium 浏览器验收。新版工作台入口位于管理员的“我的 → 注解工作台”。普通学习者既看不到入口，也不能访问管理接口。

```sh
dev-run pnpm exec playwright test tests/e2e/content-workbench.spec.ts --output=artifacts/content-workbench/playwright-results --reporter=list
```

结果：**2/2 通过，12.9 秒**。测试仅允许 localhost / 127.0.0.1 的 4186 端口，不会向公网应用或 SSH 转发端口发送测试修改。

## 已验证的真实流程

- 未登录管理请求返回 401，普通用户返回 403；管理员正常进入。
- 按册、课、字段、俄语内容定位真实项目；读取当前来源、资料版本和字段历史。
- 确认前必须填写原因并明确勾选核对声明；保存临时内容后产生可追踪的 `approve` 修订。
- 拒绝产生 `reject` 修订，保留当前候选值；恢复指定历史版本采用该修订的 `after`，新增 `rollback` 修订。
- 原始来源行指纹在审核前后保持一致；字段内容、来源和状态恢复到验收前基线；**最终全库 reviewedFields = 0**。自动化流程验收不作为语言学人工核验。
- 创建第六册、仅规范词头的真实任务，实际处理 25 / 557 项；取消和恢复后仍是已处理 25、剩余 532，最后再次取消并保留进度记录。
- 覆盖率直接读取数据库：4,835 项、32 个字段维度，适用字段 116,529；有来源、自动草稿、已审核、缺资料、争议、不适用分别展示。

## 界面与可访问性

- 360、390、430 CSS px 宽度的覆盖率、字段详情均无页面或对话框横向溢出。
- 所有可见按钮、选择器、输入框、折叠控制以及复选框对应标签的可点击区域至少为 44 × 44 CSS px。
- 三种浅色宽度与 390 px 深色共四轮 axe WCAG 2 A / AA、2.1 AA 检查，均为 **0 violations**。
- 已实际查看浅色/深色覆盖率、字段依据、编辑表单和任务进度截图，确认文字、控件和长来源信息没有遮挡或横向溢出。
- 浏览器验收发现任务列表首次返回时会关闭正在使用的新建表单；已移除依赖异步任务数量的展开状态，最终用例复测通过。

## 本地证据

证据位于被 Git 忽略的 `artifacts/content-workbench/`：

- `field-review-acceptance.json`：原字段版本、恢复版本、来源指纹、最终审核字段计数。
- `task-coverage-acceptance.json`：实际任务进度、取消/恢复结果和四轮 axe 明细。
- `coverage-{360,390,430}.png`、`coverage-dark-390.png`：覆盖率界面。
- `field-detail-{360,390,430}.png`、`field-approved-390.png`：字段来源和审核表单。
- `task-progress-430.png`：实际批次进度与操作控件。

这些是桌面 Chromium 的手机尺寸验收，**不是手机实机验收**。用户当前没有可用手机，未虚构设备证据。失败任务重试、并发租约、幂等请求、生成保护、乐观版本冲突等服务器机制另有数据库集成测试；本文件不把那些测试描述为浏览器实测。

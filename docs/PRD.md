# 俄语拾词 / Slovo 产品要求

本项目服务以中文为母语、按《东方俄语》学习的用户。核心目标是按教材与课次选择学习内容，完成有反馈的俄语记忆练习，并在下次打开时继续。用户于 2026-10-24 授权 Codex 直接实现开发提示词；权威原始要求见 `DEVELOPMENT_PROMPT.txt`，当前交付状态见根目录 `STATUS.md`。

## 主要路径

1. 登录或使用隔离演示账号，选择一册、单课或跨册多课。
2. 确认可练习数量、方向、顺序与本轮数量，开始答题。
3. 作答后阅读正确义项、来源与解释，自评后手动继续；错词隔题再练。
4. 刷新、离开或重新登录后恢复已保存内容；到期卡有独立复习入口。
5. 创建个人词库，手动录入或从实际图片识别结果整理词、短语、句子，确认后保存并学习。
6. 下载所选课次，在断网时学习；恢复联网后显示同步结果或需要处理的冲突。
7. 查看词条原始页图和详细注解；管理员以带理由的新版本修订教学内容。

## 首轮 A / B / C 验收边界

| 检查点 | 可观察结果 | 必须保留的边界 |
| --- | --- | --- |
| A | 完整导入当前工作簿、真实登录、六册和 69 课可选、双向练习、错词和历史保存 | 不用样例词库替代教材；不把一次答对称为掌握；正式调度与本轮纠错分开 |
| B | 私人词库、手动录入、真实本地中俄 OCR、编辑确认、至少 50 个可追溯代表注解 | OCR 确认前是草稿；机器候选和编写解释不标成人工审核；核心不需要云端 Key |
| C | 明确下载、账号隔离缓存、离线事件 outbox、幂等同步、冲突处理、管理修订 | 不按整张记忆状态最后写入覆盖历史；未确认事件不得静默删除；普通用户不能调用管理功能 |

每个检查点必须先运行并验证真实用户路径再继续；表格是验收要求，不代表已经全部通过。实现与证据以 `STATUS.md` 和 `artifacts/` 为准。

## 教材数据约束

当前工作簿实测：4,835 条源行、6 册、69 课、4,838 条归课关联，108 幅图像，其中 104 幅由词条链接引用。35 条缺中文；577 条有词性与词形；11 条具有来源疑误或差异标记，其中 6 条为已知体配对疑误。当前释义练习适用数为 4,795：缺释义与实质释义/词形争议排除，单纯体配对疑误不一概排除可靠中文练习。

源行、词元、义项、学习项目和方向卡分别计数。源行不按空格或斜线自动拆分，不按俄文字符串自动合并。多课同一源行复用学习项目，独立义项保持来源区别。当前一源行对应一个初始学习项目，是保守起点；词元/义项图谱不是已完成事项。

原始数据、源图、文件指纹、行号与页码不可被教学修订覆盖。第 3 册来自册末词表摘录，PDF 页码按摘录编号，不能宣称已核实六册原书无遗漏。所有词条可浏览，不可练习的条目要说明原因。

## 学习规则

- 俄选中、中选俄和自主回忆有独立方向卡状态，不能把识别能力等同拼写能力。
- 错误或忘记对应 Again，Hard 仅表示想起但困难；有提示、猜测和短时曝光保守评分。
- 错词按每张方向卡最后一条已接受记录判断：回答错误或 Again 均需巩固。同一项目任一方向仍需巩固时，错词计数记一个项目；练对某方向不会清除另一方向的错词标记。
- 首次有效尝试可形成正式事件；刚展示答案后的纠错重现是 practice，不增加 FSRS 长期熟练度。
- 错词隔 3–7 道其他题重现；不足时排在本轮末，重试有上限。单词库仅 1 个词也必须能结束学习。
- 选择题只使用真实候选；重复答案、已知同义、同词形/体配对及含糊意义排除。候选不足或目标不明确时回退自主回忆，不制造假俄语。
- 每日目标按用户时区计数，与每轮题数、正式事件数和去重学习项目数分开。统计名称必须说明实际含义。

## 内容与个人数据

个人词库内容分为单词、短语、句子，含俄语、中文、备注、例句和标签。教材加入个人集合是引用，不复制并重置记忆状态。删除集合默认移除集合和成员关系，不删除教材主库或其他集合内容。用户只能读取和修改自己的私有条目、草稿和事件。

注解栏目按词性适用：词头/重音/词性、动词体与变位、名词和形容词变格、接格、关系、例句与发音。每个字段有来源、方法、版本和状态。`unknown`、`disputed`、`not-applicable` 必须真实存在；完成体人称变化不标为现在时。50 个代表项只验证结构与流程，不代表全词库注解完成。

## 移动端和离线

中文界面、清晰俄文重音和长词布局；主要入口为今日、教材、我的词库、我的。主动作是继续学习，学习反馈保留到用户手动继续。触控目标至少 44px，支持系统暗色、大字号、软键盘和减弱动画。360/390/430px 是浏览器验收宽度；模拟器结果不得标成 iOS/Android 实机结果。

已显式下载的课次与本地会话可离线使用。图片、音频、OCR 模型是否已取得要明确；未缓存资源不冒充离线可用。首次认证需联网；退出撤销离线身份，但保留按原账号隔离的未同步事件。用户主动放弃前不能清空。

## 后续完整产品

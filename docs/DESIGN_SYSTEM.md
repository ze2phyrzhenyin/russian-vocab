# 俄语拾词界面规范

方向：像一本每天愿意打开的语言手册。温暖纸色、深墨文字、克制的森林绿，重点放在俄文、回想和下一步操作。中文使用系统字体，俄文重点使用系统衬线；不依赖外部字体下载。

颜色由 `src/app/globals.css` 的 CSS 变量控制。纸底 `#f7f5ef`、正文 `#273a32`、主动作 `#315747`、淡绿 `#e7ede1`、暖色 `#eed8b9`。暗色模式有独立语义变量；文字和状态不能只靠颜色表达。

桌面左侧固定导航，手机底部四入口「今日 / 教材 / 我的词库 / 我的」。今日突出一个继续学习动作；统计从服务器实际数据取得，离线有清楚标记。选课支持跨册，计数采用源词条、学习项目、方向卡不同口径，不把课次关联当成多个已掌握词。

学习屏保留轻量进度、可换行的题干和拇指可达选项。选答后显示解释，用户可以校正回忆评价和标记提示/猜测，点击「保存并继续」后将事件与会话位置写入 IndexedDB，再进行同步。原页或详情以模态窗口打开，关闭后回到原题。小词库或歧义降级为翻卡时说明原因。

原生 dialog 提供模态焦点、Escape 关闭及返回焦点；输入有标签，错误用 alert，进度与消息用 status。交互触控区域不低于 44px。所有长俄文、ё、组合重音和中文多义释义允许换行，不省略重要内容。动效以 180–200ms 为主，MotionConfig 和 CSS 都遵循 prefers-reduced-motion。

照片识别提供原图、旋转和百分比裁剪；限制 15MB / 4000 万像素输入和 2400px 识别边。真实俄语/简中模型在本项目托管，按需加载。显示引擎进度、置信值与文本框坐标；自动分行只是编辑起点，用户可合并/拆分，确认后才入库。草稿按账号隔离，取消、错误、关闭后保留。

离线外壳只缓存公开 HTML/静态构建资源。安装时从公开首页提取同源 `/_next/static/` 资源并缓存，避免首次打开时资源早于 Service Worker 加载而遗漏。下载按钮收到当前控制页面的离线外壳确认后才显示“可离线练习”；准备超时会保留词条并提示重试。API、认证、原图与 OCR 模型不进入 Service Worker 缓存。课次、会话、答题 outbox 与图片草稿放在按账号隔离的 IndexedDB；退出撤销本机离线访问，不静默删除待同步记录。

验收宽度：360、390、430px，另检查桌面 1440px、深色、减弱动画、长句及大字号。Playwright 仿真不能记为 iOS/Android 实机测试。速度与帧率仅报告实测结果，不凭视觉判断。

2026-10-24 补充验收：`tests/e2e/compatibility.spec.ts` 在生产构建上 4/4 通过。已检查 360/390/430px 可点击目标至少 44px、真实保存的俄语长句与中文长释义、深色和 200% 计算字号。Chromium 4 倍 CPU 降速、离线缓存状态下，各方向 10 次选择题点击至反馈 DOM 更新的 p95 分别为 4.6ms（俄→中）、4.0ms（中→俄）；首次动画帧机会最大值为 14.6ms、41.6ms，这不是屏幕实际绘制时间。实际 WebKit 27.2 引擎配合 iPhone 13 参数仿真通过离线刷新、恢复位置、3 条记录同步，零页面异常。原始样本与截图位于 `artifacts/compatibility/`；未把这些结果表述为手机实机验收。

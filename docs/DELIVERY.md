## 体验顺序

1. 用交付的普通账号登录公网，选课后开始双向选择或翻卡。
2. 在“我的词库”建立自己的集合，手动输入或用图片OCR；核对预览后保存。
3. 联网下载课次后断网答题，重新联网查看同步结果。
4. 以独立内容管理员登录，“我的 → 注解工作台”查看真实覆盖率，核查单字段、填写依据并确认；在历史中选择版本并填写原因恢复。

用户明确目前没有可连接手机，因此仅完成真实Chromium/WebKit引擎与移动视口验收，不称为iOS/Android手机实机验收。未知内容仍需收集可靠证据与实际审订；高级拼写/听音/语法题和跨源词元义项归并仍是产品扩展。第3册现有来源为17页摘录，不宣称六册原书无遗漏。

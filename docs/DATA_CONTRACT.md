## 运行入口

```sh
dev-run python3 scripts/extract_vocab.py --file data/source/东方俄语词汇汇总_第1至6册.xlsx
dev-run python3 -m unittest discover -s tests/importer -v
```

也可使用 `VOCAB_SOURCE_PATH`；明确 `--file` 优先。Python 3.11+ 与 Pillow 必需。脚本只读取原工作簿，不保存或重写它；不会访问数据库。

输出：

- `data/processed/workbook.json`：契约 v1 的原始来源数据，交给数据库导入器。
- `data/assets/original/`：逐绘图对象的原始媒体字节，SHA-256 可复核。
- `data/assets/thumbnails/`：独立缩略图，最长 420×620，不替代原图。
- `artifacts/import/import-report.json`：逐册、逐课、来源文件、覆盖率及基线差异。
- `artifacts/import/issues.json`：缺义、疑误和受影响字段。
- `artifacts/import/drawing-mapping.json`：工作表锚点、绘图关系、媒体部件与图片尺寸。
- `artifacts/import/version-diff.json`：与上一份有效提取结果逐条比较。

数据文件与教材图像保持私有并被 Git 忽略，不放在 `public/` 或页面首屏包中。应用通过需要登录的资源路由按需提供原图。

## 字段与身份

顶层、SourceRow、SourceImage 字段以 [CONTRACT.md](CONTRACT.md) 为准。`rawColumns` 保留全部原始列值；`originalLinkFormula` 单独保留公式文本，避免读取缓存“查看原表”而丢失目标。原俄文、重音、ё、й、备注与配对字符串均不改写、不按空格或斜线拆词。

`sourceKey` 形如 `dongfang:b1:s1`，由册数和源序号组成，独立于工作簿哈希和俄文字符串。文件哈希用于标识来源版本，不作跨版本学习项目 ID。相同来源 ID 的俄文或源文档变化被列为身份冲突，源 ID 消失也须核对；脚本保存 `candidate-<sha256>.json` 并失败退出，保持上一份有效 `workbook.json`。数据库层不得为绕过这个核对而删除旧记录或重置学习状态。

同一来源 ID 的原始释义、页码、备注变化会出现在版本差异中。它们是来源版本更新，不能覆盖人工修订。新增源行是候选新增条目，不能单凭相同俄文与已有条目合并。原词条、义项、词元、学习项目和卡片须各自计数；本提取器只确认源行和归课关系，未自动生成或合并词元和义项。

`report.sourceDocuments` 保存源 PDF 文件名、册数、源表行号、PDF 页码范围和书内页码范围。第 3 册源文件是 `提取自大学俄语东方（新版）学生用书3.pdf`，PDF 第 1–17 页对应书内第 272–288 页。其课内补充没有在当前材料中核对。

## 图片映射

依次解析 workbook → sheet → drawing → image 的 OOXML relationships。保留所有 108 个图像对象，包括没有源词条直接链接的 4 张核对图。读取 `IFERROR(HYPERLINK(...))` 内的字面量工作表目标，再定位标题区域内唯一图像，并核对图片标题中的册数、PDF 页、书内页和源文件身份与原行一致。任何缺失或歧义会写失败报告，保持上一份有效提取结果，退出非零；不跳过该词条。

108 张图均成功解码并生成缩略图；4,835 行映射成功，覆盖率 100%。额外 4 张是第 2 册 PDF154、第 5 册 PDF16、第 6 册 PDF12 与 PDF96。它们作为核对资源保留，不能从“没有直接链接”推断为无用。

代理进行了第 1 册书内250、第 3 册书内272、第 5 册书内221的视觉抽样，标题和页码一致；第 5 册原图也确实保留了 отбить 等体标记疑误。此抽样不是语言专家或人工审核事件，不应生成“人工核验”标签。

## 缺项与可练习状态

`report.issues[]` 字段：`sourceKey,rowNumber,book,lessons,russian,code,affectedFields,reason,sourceNote`。

- `missing-meaning` / `affectedFields: ["chinese"]`：35 行，不把占位字符串当答案。
- `aspect-dispute` / `["aspect","aspectPairs"]`：отбить、отделаться、откликнуться、попереть、постелить、прописать。体与配对不可作为已确认语法答案；中文释义未被此标记自动判错。
- `source-dispute` / `["russian"]`：ручье́ / ручеёк 的原文问题。
- `source-dispute` / `["chinese"]`：сцена、вроде кого-чего、процентный、тарифный 的原译疑误。

`disputed` 仅表示存在待核查问题；不能一概推断所有字段均不可使用。按现有源字段检查，4,795 行具有可用于释义学习的俄中内容（其中 6 行仍带体关系警示）。这只是源字段可用性，不保证选择题干扰项不歧义；题目生成器仍须独立检查。

11 项 Python 验证覆盖：不固定表头行、公式目标、相对关系、缺图拒绝、身份冲突候选、重复源 ID 拒绝、相同输入幂等、原文件未变、重音/ё/й、真实工作簿计数与第 3 册摘录身份。数据库导入幂等和学习状态保留由集成验证另行负责。

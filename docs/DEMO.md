# 五分钟体验

本机入口 <http://localhost:4186>；rex-cli 经 SSH 转发后为 <http://localhost:4187>。命令见根 README。可用“一键体验”，全新用户为 `new@ruslearn.test / RusDemo!2026`。

1. **选课**：进入“教材”，选第 1 册第 1、2 课，也可跨册组合。在学习设置选择双向练习、每轮 10 题。缺释义和争议项有不可练习原因。
2. **答错与再练**：故意选错，阅读正确答案和解释，再点“保存并继续”。隔题再次遇到错词；小词库会降级为翻卡。短时再练不重复提升长期状态。
3. **保存与恢复**：左上返回暂停，刷新或退出后重新登录，从“继续上次学习”恢复。“我的”显示实际练习历史，服务端确认后才清除待同步事件。
4. **个人词库**：创建集合，录入单词 `книга | 书`、词组 `доброе утро | 早上好`、句子 `Я читаю. | 我在读书。`，选择相应类型，填写备注、例句和标签，再进入学习。
5. **图片入库**：在集合里选择图片识别，上传 `tests/fixtures/ru-zh-sample.png` 或自己的印刷体照片。实际识别后，对照原图编辑中俄配对及类型，勾选确认再保存。首次模型加载时间取决于设备与网络；置信度不等于正确率。

## 离线与管理

- 教材页下载所选课次，完成后断网学习。答题先进入当前账号 IndexedDB；刷新后位置保留。联网等待待同步归零，重传不能多计。
- 跨设备状态或异常时钟进入冲突。在“我的”查看原因，选择“保留为练习”或“放弃”，保留练习不推进 FSRS。
- 退出保留未同步队列归属。另一账号不能看见之前账号的集合、草稿或下载内容。
- 管理员随机密码在各环境 `.local/demo-access.md`。在“我的”内容维护中查看缺项、填写修订原因并保存；版本、操作者、前后值留存，Excel 原始行不被覆盖。普通用户没有管理权限。
